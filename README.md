# Jumping raven 2: survive in Snezhinsk

2D платформер-шутер на Pygame с одиночным и мультиплеерным режимами.

## Возможности

- Одиночная игра
- Мультиплеер
- Несколько видов оружия
- Хук для перемещения по карте
- Динамичный геймплей в стиле Teeworlds
- Создание собственных карт

## Описание

Игра представляет собой 2D платформер-шутер с акцентом на движение, стрельбу и взаимодействие с картой. Игроки могут сражаться друг с другом в мультиплеере или играть в одиночном режиме.

В игре доступны различные виды оружия, механика хука и возможность создавать собственные уровни.

## Технологии

- Python
- Pygame
